# 消息发送失败排查：通用检查清单

消息发送失败时先确认失败发生在哪一段：触发条件未命中、模板渲染失败、接收人为空、发送策略拦截、通道配置异常、第三方网关失败，还是状态回写失败。不要一开始就只看通道，很多失败实际发生在业务条件或模板变量阶段。

排查顺序建议：

1. 查看发送记录的状态、错误码、templateCode、channelType、receiver 和业务主键。
2. 校验业务配置是否启用，单据、动作、租户、应用编码是否匹配当前请求。
3. 校验模板变量是否都有值，HTML、JSON 或富文本内容是否可以渲染。
4. 检查接收人解析结果，手机号、邮箱、用户 ID 是否为空或格式错误。
5. 检查频控、时间窗口、通道限制、黑白名单等发送策略是否拦截。
6. 对具体通道做连通性或测试发送，并查看 Java 平台日志和第三方返回。
